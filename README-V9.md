# Safe Space 笑話急轉彎 v9

本版以 v8 完整專案為基礎，只調整 `js/features/jokes.js` 與 `css/features/jokes.css`。

## v9 行為更新

### 急轉彎答案流程

1. 使用者選擇預設猜法或自行輸入答案。
2. 笑友先回應並直接公布「答案」。
3. 不立即解釋笑點。
4. 顯示三個「知道答案後，你想怎麼回？」選項。
5. 使用者選擇後，笑友才解釋梗並繼續聊天。
6. 最後進入本輪評價。

### 多回合聊天

- 每次配對的聊天會隨機設定本次最多 1～3 個笑話。
- 每一輪笑話結束、使用者完成評價後，若尚未達上限，會出現：
  - `💬 再聽一個`
  - `🌿 今天先這樣`
- 使用者選擇繼續後，同一位笑友會再講下一個笑話。
- 笑友也可能依角色風格隨機主動結束聊天。
- 達到本次隨機上限後，會自動結束。
- 結束時會顯示：`XX 已離開聊天室`，並提供回到笑友列表的按鈕。

### 真人感

沿用既有 `humanDelay()` / `queueFriendMessages()` / `sessionId` 機制；本版沒有把訊息一次性注入，仍會逐則顯示 typing indicator 與隨機延遲，並防止舊聊天室的延遲訊息跑入新聊天室。
